Moment 3: Skapa webbsida Norrgläntan - natur upplevelse med HTML och design med hjälp av CSS
------------------------------------------------------

Beskrivning:

Detta är en webbsida som skapades i Laboration 3.

Webbsida heter Norrgläntan och handlar om natur upplevelse. I webbsidan kan man hitta olika aktiviteter, bokar boende, adress, kontakt information mm. 
------------------------------------------------------

Teknik:

Webbplatsen är skapad med:
 - HTML
 - CSS
 - Flexbox
 - CSS Grid
 - Mobile-first
 - Media queries
